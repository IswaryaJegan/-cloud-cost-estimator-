# ☁️ Cloud Cost Estimator

An interactive tool to estimate monthly cloud costs across AWS, Azure, and Google Cloud.  
Adjust instance type, storage, and data transfer — see real-time pricing breakdown.

## Features
- Multi-cloud support (AWS, Azure, GCP)
- Instance sizes from nano to x-large
- Storage and data transfer sliders
- Instant cost update with detailed breakdown
- Modern dark UI, fully responsive

## How to run
1. Clone this repository
2. Open `index.html` in any browser
3. Play with the sliders and see cost changes

## Tech stack
- HTML5, CSS3, JavaScript (vanilla)
- No external libraries or backend

## Use case
Ideal for FinOps demos, cloud internship projects, or understanding cloud pricing models.
